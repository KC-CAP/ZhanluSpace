# PDF、DOCX 与 OCR 素材接入计划

> 状态：待评审；必须在第一阶段个人闭环稳定后单独实施，不与团队 GitHub 工作流混合。

## 目标

在不改变现有 JSONL 协议、知识提案 Schema、风险分类和 Git 事务语义的前提下，把素材获取层扩展到：

1. 可提取文本的 PDF；
2. DOCX；
3. 扫描 PDF；
4. PNG、JPG/JPEG、WebP 图片 OCR；
5. 可选的 Git LFS 原件存储。

PPTX、XLSX、音频和视频不属于本计划。

## 不可破坏的约束

- 原始二进制永远作为不可信输入，解析器不能执行宏、外部链接、嵌入对象或脚本。
- `source_id` 继续由规范化文本内容决定；另存原件 SHA-256，用于审计同一原件和不同提取版本。
- Hermes 仍只接收有大小上限的规范化文本，不接收 Vault 路径、Git 凭据或解析器临时路径。
- OCR/解析质量、页码、字符区间和提取器版本必须写入 Source Frontmatter/manifest。
- 任何外部解析程序都使用参数数组、隔离临时目录、显式超时和进程树终止，不通过 Shell 字符串调用。
- 同一原件和同一提取器版本重复导入必须幂等；提取器升级产生可解释的新提取记录，不静默改写旧来源含义。

## 技术决策检查点

实施前制作一个小型选型记录，比较候选 PDF/DOCX/OCR 组件的：许可证、Windows 安装体积、离线能力、中文质量、页码坐标、密码文件行为、畸形文件防护和可复现实验结果。不得只因“容易安装”就确定依赖。

推荐的边界是 Python 进程内解析普通 PDF/DOCX，OCR 引擎通过独立适配器调用。Git LFS 作为可选外部工具检测；缺少 LFS 时可以保留规范化文本但必须明确提示原件未进入版本库，不能悄悄提交大文件。

## 实施任务

### 任务 1：扩展素材类型和元数据 Schema

- 为 `NormalizedSource` 增加页数、原件 MIME、原件 SHA、提取器版本、OCR 语言、质量警告与页段映射。
- 保持旧 Markdown/TXT/URL 记录可读；为新字段写迁移兼容测试。
- 对扩展名、MIME 魔数、文件大小、压缩炸弹、加密文档和页数上限分别测试。

### 任务 2：文本 PDF 适配器

- 先用自生成、可再分发的小 PDF 写失败测试：中文、页眉页脚、空白页、旋转页、损坏文件和加密文件。
- 输出按页分隔的确定性纯文本与页码引用，不把视觉阅读顺序的猜测伪装成确定事实。
- 如果文本覆盖率过低，把素材路由到扫描 PDF OCR，而不是交给 Hermes 猜测。

### 任务 3：DOCX 适配器

- 只读取段落、标题、列表、表格文本、脚注/尾注等批准内容；拒绝宏和外部对象。
- 保留段落/表格定位信息，生成稳定引用锚点。
- 测试损坏 ZIP、超大嵌套、外部关系和无文本文件。

### 任务 4：图片与扫描 PDF OCR

- 使用统一 OCR 请求/响应接口，包含页号、块坐标、文本、置信度和语言。
- 为低置信度、混合中英文、竖排、倾斜、重复页和无文本图片设明确警告。
- 扫描 PDF 逐页处理并设总像素、页数、并发和超时上限；失败可恢复到具体页。
- OCR 文本进入 Hermes 前仍经过相同规范化和上下文上限。

### 任务 5：原件和 Git LFS

- 默认阈值内的原件可按 `sources/<kind>/<sha>/original.<ext>` 保存；超过阈值必须要求 LFS 或选择“不保存原件”。
- 检测 `git lfs version`、仓库 attributes 和 push 前对象完整性。
- 事务提交必须包含规范化来源、原件/LFS pointer 和 manifest 的一致性校验。
- 克隆缺少 LFS 对象时，知识和规范化文本仍可读，但 UI 明确显示原件不可用。

### 任务 6：Obsidian 体验

- 拖放扩展到批准格式，显示文件类型、大小、预计 OCR 路由和隐私去向。
- 显示解析页数/OCR 页数进度；允许取消并清理子进程。
- 完成页显示提取质量和警告，不把 OCR 低置信内容标成高置信知识。

### 任务 7：端到端和安全验收

- 每种格式至少一条真实 CLI→适配器→Hermes 替身→编译器→Git 的 E2E。
- 畸形/超大/密码/取消/超时测试证明 Vault 不被部分写入。
- 在 Windows 上完成真实 OCR 冒烟；记录引擎、语言包、许可证和安装体积。
- 更新一键验证、安装脚本、手工验收、许可证审计和明确限制。

## 验收标准

- 支持格式的每条知识引用能回到页码或段落/表格位置。
- 文本 PDF 与扫描 PDF 路由可解释且可重复。
- 低质量 OCR 产生警告和风险提升，不会静默进入低风险自动合入。
- 二进制解析失败、OCR 超时、取消和 Git LFS 缺失不修改正式 Vault。
- 没有引入未经审计的 AGPL/GPL 代码到发行 bundle；若依赖外部程序，安装和许可证边界写清楚。
